# FarmOS — Smart Farm Management

FarmOS runs a dairy and poultry farm in one place: cows and calves, hens and ducks,
feed stock, veterinary records, milk production, milk delivery, customers, income,
expenses and profit. It is built for Bangladesh (Bangla/English, ৳, bKash/Nagad/Rocket)
and stays configurable for other countries.

**Stack:** Laravel 13 API · React 19 + TypeScript (Vite) · PostgreSQL · Redis · Laravel Reverb (websockets)

Why it feels fast, and why the numbers always add up, is explained in
[docs/ARCHITECTURE.md](docs/ARCHITECTURE.md). Deployment, backup and restore are in
[docs/OPERATIONS.md](docs/OPERATIONS.md).

```
backend/    Laravel API (domain services, ledgers, tests)
frontend/   React SPA / PWA

```

## Quick start (local development)

Requirements: PHP 8.4+, Composer, Node 20+. Local development uses SQLite, so no
database server is needed.

```bash
cd backend
composer install
cp .env.example .env
php artisan key:generate
php artisan migrate --seed     # demo farm with 30 days of history (~1 min)
php artisan serve              # http://127.0.0.1:8000
```

```bash
cd frontend
npm install
npm run dev                    # http://localhost:5173 (proxies /api to :8000)
```

Sign in with the demo owner account **owner@farmos.test** / **password**. Other demo
roles use the same password: `manager@`, `worker@`, `delivery@`, `accountant@farmos.test`.

Optional live updates between devices:

```bash
# backend/.env → BROADCAST_CONNECTION=reverb
php artisan reverb:start
# frontend/.env.local → VITE_REVERB_APP_KEY=farmos-local-key  VITE_REVERB_PORT=8080
```

Alerts (low stock, vaccinations due, overdue payments, milk drop…) are generated by the
scheduler. In development, run them once with `php artisan farmos:alerts`, or keep
`php artisan schedule:work` running.

## Tests

```bash
cd backend && php artisan test     # 21 tests: units, auth, tenancy, roles, milk→delivery→invoice→payment,
                                   # inventory, poultry, vet, idempotency, full 30-day reconciliation + endpoint smoke
cd frontend && npm test && npm run build
```

`ReconciliationTest` runs the whole demo through the domain services and proves that:
- the trial balance balances,
- AR equals customer balances and AP equals supplier balances,
- inventory value equals the ledger,
- milk produced minus delivered minus used equals stock,
- revenue equals invoices,
- no document is posted twice,
- the dashboard agrees with the reports.

## Modules

| Area | What works |
|---|---|
| Dashboard | Live KPIs, milk trend, revenue vs expenses, expense mix, population, alerts, today's tasks and upcoming vet care. It is computed from records and cached per farm version. |
| Livestock | Register (born, bought or gift), profile, weights, breeding and calving events, sale, death and transfer (history kept), archive and restore, milk chart, linked costs |
| Poultry | Flocks, daily log (eggs, deaths, sales) with closing-count validation, egg and bird sales posted as income |
| Feed & inventory | Items, opening stock, purchases at landed cost, consumption per cow or flock, wastage and spoilage, stock counts, low-stock and expiry alerts, a full movement ledger |
| Veterinary | Treatments (with prescribed medication), vaccinations, follow-ups. Costs create exactly one linked expense. |
| Milk | Daily milking sheet (morning/evening), internal use and spoilage, milk stock ledger, 30-day trend |
| Deliveries | Generated from customer schedules, one-tap delivered, partial and cancelled, cash collection on delivery, oversell protection, print and CSV |
| Customers | Profiles, pricing, schedules, FIFO payment allocation, advances, account statements |
| Income / expenses / suppliers | Sales and invoices, receipts, bills (expense, stock or asset), supplier payments, custom categories |
| Reports | Profit and loss, cash flow, profit by business area, profit per cow or flock, receivables aging, payables, milk reconciliation, feed. All exportable and printable. |
| Team | Employees, salary, advances and deductions, tasks (recurring), notifications |
| Platform | Six roles enforced server-side, farm data isolation, idempotent writes, audit log, offline outbox, English and Bangla, dark mode, PWA |
